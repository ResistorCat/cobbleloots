### Changes

- **Debug Commands**: Added `/cobbleloots debug weights` and `/cobbleloots debug check <id>` commands for server operators and pack creators.
  - `/cobbleloots debug weights [source_type] [pos]`: Displays a sorted breakdown of eligible loot balls and their relative spawn probabilities at any coordinate or biome.
  - `/cobbleloots debug check <id> [source_type] [pos]`: Performs a comprehensive filter-by-filter diagnostic showing passed and failed conditions with visual indicators.
